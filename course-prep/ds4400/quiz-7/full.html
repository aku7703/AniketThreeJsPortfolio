Ridge and lasso: fit plus a price on size

Which tool, and why? Lasso vs ridge from the context

Lasso → too many features, throw some out. It “induces zeros”: it says a feature is not important and drops it. Reach for it when there are many more features than samples, or you believe only a few features matter (HW7 Q1: 3 of 20 powers). Ridge → correlated features. When X has correlated columns (his example: height, weight and shoe size), OLS can trade one for another, so its weights have high variance. Ridge shrinks them, adding a little bias to cut that variance (HW7 Q2: rooms vs area).

Forests and feature importance

Forests and feature importance: when to trust the bars

Course definition: a feature’s importance = total Gini decrease from every split on that feature, across all trees, as a % of the forest’s total decrease. It measures how much the forest used the feature. It has no direction, is not a correlation, and is not causation.

Three-step reading rule:

  1. Does the classifier work? Compare CV accuracy to the baseline “always guess the majority class” = max(p, 1−p). If CV accuracy is not clearly above that, set the plot aside: nobody cares what a useless model relies on.
  2. If it works, name the top features and their share (“about two thirds of the Gini decrease comes from…”).
  3. Never read direction or causation from a bar. To learn how a feature relates to y, look at the data.

1. Standardize first

Feature A is in meters (0–2), B in grams (0–5000). Lasso zeros A. Should we conclude A is useless?

Full worked solution

No. Without standardizing, A needs a much larger weight for the same effect, and the L1 penalty charges that heavily, so lasso drops it for its units. Standardize both columns, then compare.

2. Training error vs λ

Training MSE rises steadily as λ goes 0 → 100. Is λ = 0 best?

Full worked solution

Not necessarily: a penalty can only worsen the training fit, so training MSE always prefers λ = 0. Choose λ by cross-validated MSE, which measures error on unseen rows.

3. Bad baseline

Fraud is 2% of transactions; the forest’s CV accuracy is 97%. Read the importance plot?

Full worked solution

No: always guessing “not fraud” already scores 98%, so 97% is below the baseline and the forest has not learned anything useful. Set the plot aside.

Split S puts 1 sample in a pure left child and 99 in a right child with Gini 0.49 (parent 0.50). Split T makes two children of 50 with Gini 0.30 each. Which is better?

T. S’s weighted Gini is 0.01(0)+0.99(0.49)=0.4850.01(0)+0.99(0.49)=0.4850.01(0)+0.99(0.49)=0.485 (reduction 0.015); T’s is 0.300.300.30 (reduction 0.20). A tiny pure child carries tiny weight.

5. Ridge vs lasso choice

You suspect only 5 of 300 sensors matter. Ridge or lasso? Why?

Full worked solution

Lasso: its L1 penalty can set weights exactly to zero, so it selects the few sensors that matter; ridge shrinks all 300 but keeps them non-zero. Refit OLS on the selected sensors to undo lasso’s shrinkage.
