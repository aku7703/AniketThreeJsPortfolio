1. Huffman coding

Merge A+B=6, 6+C=15, 15+D=31, then 31+E=66.

A=0000, B=0001, C=001, D=01, E=1. The encoding of BED is 0001101.

Total length is 2×4 + 4×4 + 9×3 + 16×2 + 35×1 = 118 bits. This equals the sum of the four merge weights.

2. Test a greedy rule

Target 6. Greedy takes 4+1+1, while 3+3 uses two coins. No single coin has value 6. For targets 1 through 5 the greedy counts are 1, 2, 1, 1, 2. Targets 1, 3, and 4 are single denominations, and 2 and 5 need at least two coins because neither is a denomination.

3. Schedule inspections

Process jobs by increasing end time. If the most recent inspection misses the next job, place a new inspection at that job’s end.

sort jobs by increasing end
times = []
for (start, end) in jobs:
    if times is empty or times[-1] < start:
        append end to times
return times

Trace. Add 3 for (1,3). It covers (3,4) and (2,5). Add 6 for (4,6). It covers (6,8). Add 9 for (7,9). Return [3,6,9]. The empty input returns an empty list.

Proof. Let I be an interval with the smallest end e. An optimal solution has some time t in I, so t ≤ e. Every interval containing t starts at or before t and ends at or after e. Moving that inspection to e therefore preserves coverage and uses at most the same number of inspections. Some optimum thus includes e. Remove the intervals it covers and apply the same argument to the remainder. In the sorted scan, any earlier inspection is at or before the most recent one, and the most recent one is at or before the current interval’s end. So the code adds a time exactly when the current interval is uncovered.

Time. O(n log n) to sort and O(n) to scan. Check that the condition uses strict <, since a time equal to the next start already covers that interval.
