2. Check a one-pass rule

An array contains positive side lengths in descending order. A proposed algorithm checks only the first three lengths. If they form a triangle, it returns their perimeter. Otherwise, it returns 0. Give a four-element counterexample and explain what the algorithm can safely discard when that first triple fails. Handle the equality case explicitly.

3. Assign carts

Each crate has positive weight at most L. A cart holds at most two crates and their combined weight cannot exceed L. Every crate must be assigned to exactly one cart. Given an array of crate weights, return the minimum number of carts.

Give a greedy rule and complete pseudocode. Trace your code with L = 10 and weights [7,2,9,5,4,3,8]. Your trace should show which crates each cart carries. Prove optimality and state the running time. Explain what your code does when exactly one crate remains.
